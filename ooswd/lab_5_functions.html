Notation in assignment specifications
  • Angular brackets containing descriptive text are placeholders, used to describe required input or other literals. For example,
    • if an expected input string value is described as <name> then the actual value could be John or Mary
    • if a value is described as <date of birth in format dd/mm/yy> then the actual value might be 01/01/01

    The actual value should not include angular brackets.

  • If a command line window is shown to demonstrate requirements,
    • text printed by the programe is displayed in white

Exercise 2: Calculator

  • Write a function that takes three arguments: integers and a string with one of the following values: '+', '-', '*' or '/'. The function should perform the operation corresponding to the given string on the two number parameters and return the result of the operation. It should handle all cases of invalid arguments by printing an informative message and returning None. Name your function and parameters suitably, based on their meaning.
  • Make a comprehensive list of tests for the function, each consisting of a call with different arguments.
  • Perform the tests and fix any problems with the function that are revealed by the testing. Repeat this process until the function works correctly.

Exercie 3: Menu

  • Write a program in Python that presents the user with a menu that contains three numbered options: (1) table, (2) arithmetic and (3) exit.
  • If the user picks the table option, they are asked for the number of columns and rows and the table printing function is called with those arguments, then the main menu is shown again. Validation of the input must be performed (we don't necessarily have a cooperative user).
  • If the user picks the arithmetic option, they are asked for two numbers and an operation, the calculator function is called, the result printed and the main menu shown again. Validation of the input must be performed.
  • If the user picks the exit option, the program ends.
