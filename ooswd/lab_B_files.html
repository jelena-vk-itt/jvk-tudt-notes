School of Computer Science

Files Lab

Assignment

  1. Define a class to model an animal (fields species, name, age, weight) and add property getters and setters for all fields, which should be private.
  2. In a separate Python file, define a class that models a zoo with any number of animals. The zoo should be initially created empty and equipped with methods for:
    • adding individual animals
    • compiling a transfer list of 10 randomly chosen animals, which is written to a CSV file
    • a method in the zoo class that converts weights from pounds to kilograms and the other way around, depending on the value of a boolean parameter
    • a method that calculates and returns the mean weight of all the animals of a specified species and returns it
  3. In another Python file, define a class that reads CSV files. It should have a method that takes a file name and a list of types (corresponding to columns in the file) as arguments and reads and stores the data from the file. It should also store a list of problematic rows (with invalid column counts and column types), leaving the problematic rows out of the stored data. It should also have methods that return the data and the problem list respectively.
  4. A fourth Python script should define and execute tests for all the functionality implemented in the classes above.
  5. Using mockaroo.com create a CSV file that has animal data for 200 animals.
  6. A fifth Python script should use the defined classes to read the CSV file, create a zoo including all the animals and run the transfer, conversion and average weight methods on it.
